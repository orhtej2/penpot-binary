# About

Just an action which runs Every 8 Hours to extract latest Penpot backend, frontend and extractor, and make a release in this repo.

When started manually, the workflow can optionally be given a Penpot release tag. If the tag is left empty, it extracts the latest upstream release as usual.

Penpot itself is a subject to its original license (MPL) here: https://github.com/penpot/penpot/blob/develop/LICENSE
